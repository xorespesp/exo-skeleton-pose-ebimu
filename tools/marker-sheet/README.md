# marker-sheet

sagittal 색 마커 검출 모드용 인쇄 시트 생성기. 설계 배경은 `docs/color-marker-detection.md`.

정확한 mm 치수의 벡터 PDF를 뽑는다. 색 원판, 그 둘레의 검정 링, 인쇄 배율 확인용 자 눈금,
카메라로 측정할 색 패치가 한 장에 들어간다.

## 실행

설치 과정이 없다. uv가 의존성을 알아서 받는다 (PEP 723 인라인 메타데이터).

```
uv run tools/marker-sheet/marker_sheet.py --out markers.pdf
```

기본값은 마젠타 + 시안, 지름 18 mm, 링 1.5 mm, 색당 12개, A4다.

## 주요 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--out` | `markers.pdf` | 출력 경로 |
| `--diameter` | `18` | 색 원판 지름 [mm] |
| `--ring` | `1.5` | 원판 둘레 검정 링 두께 [mm] |
| `--colors` | `magenta,cyan` | 프리셋 이름, `#RRGGBB`, `이름=#RRGGBB`, 또는 `all` |
| `--count` | `12` | 색당 마커 개수 |
| `--paper` | `a4` | `a4` 또는 `letter` |
| `--label` | (없음) | 시험소·프로파일 이름. 시트에 인쇄된다 |
| `--no-cut-guides` | | 재단용 점선 원 생략 |
| `--report-only` | | PDF를 만들지 않고 색 분리도만 출력 |

프리셋은 `magenta` `cyan` `orange` `green` 넷이다. 빨강·노랑·파랑은 각각 피부톤/안전표시,
따뜻한 조명에서의 백색 근접, 작업복과 겹쳐서 제외했다.

## 색을 고르는 순서

**색 값 자체는 정확할 필요가 없다.** 검출기의 색 모델은 어차피 카메라로 샘플링해서 만든다.
시트가 보장해야 하는 것은 셋뿐이다.

1. 같은 클래스의 마커가 전부 같은 색일 것
2. 두 클래스가 `a*b*` 평면에서 충분히 떨어져 있을 것
3. 지름이 표기값과 일치할 것

2번은 툴이 숫자로 알려준다.

```
$ uv run tools/marker-sheet/marker_sheet.py --colors all --report-only

color        hex        L*      a*      b*
magenta      #E6007E    49.9   +79.1    -2.6
cyan         #00A0E9    62.5    -8.7   -46.3
orange       #F26522    60.2   +51.2   +60.7
green        #00A651    59.8   -55.7   +33.8

a*b* separation (larger is easier to separate)
     magenta <-> cyan         98.0
     magenta <-> orange       69.2
     magenta <-> green       139.5
        cyan <-> orange      122.6
        cyan <-> green        92.8
      orange <-> green       110.2
```

다만 **클래스끼리의 거리만으로 정하면 안 된다.** 배경도 같은 평면에 있다. 실험실 배경은
대체로 무채색이라 원점 근처에 모이고, 피부톤은 대략 `a*+15 b*+18`에 앉는다. 원점에서 먼
색일수록 배경과 안 겹친다.

```
원점(무채색)까지의 거리
  magenta 79.1    orange 79.4    green 65.1    cyan 47.1
```

그래서 실제 결정은 **`--colors all`로 한 장 뽑아 현장 배경과 함께 카메라로 찍어 보고**,
`a*b*` 산점도에서 배경 구름과 가장 멀리 떨어진 쌍을 고르는 것이다. 기본값 마젠타+시안은
두 지표가 모두 무난한 조합이고, 초록 안전표시가 ROI 안에 없다면 마젠타+초록이 분리도는 가장 좋다.

## 인쇄 규칙

- **반드시 100% / 실제 크기로 인쇄한다.** "페이지에 맞춤"을 쓰면 지름이 틀어지고,
  지름은 미터 스케일에 그대로 들어간다
- 자르기 전에 **자 눈금이 정확히 100 mm인지 재서 확인**한다
- **무광 용지만 쓴다.** 광택지는 정반사 하이라이트를 만들어 채도를 0으로 떨어뜨리고,
  블롭 한가운데 구멍이 뚫려 centroid가 편향된다
- 같은 프린터, 같은 설정으로 뽑는다. 시트마다 색이 달라지면 색 모델이 무의미해진다

## 시트에 같이 인쇄되는 것

**자 눈금** 100 mm 스케일바. 인쇄 배율이 틀어졌는지 확인한다.

**색 패치** 클래스별 18 mm 정사각형. 카메라로 이 패치를 찍어 색 모델을 샘플링한다. 원판보다
크고 평평해서 픽셀 표본을 넉넉히 뽑을 수 있다.

**회색 기준 패치** `#808080`. 런타임 조명 보정이 매 프레임 읽는 기준이다. 시야 안 고정 위치에
붙여 두면 조명 색온도가 서서히 변해도 색 모델이 유지된다.

**검정 링** 배경이 디포커스나 블루밍으로 원판 가장자리에 번지는 것을 막는다. 번지면 측정
centroid가 끌려간다.

**재단 점선** 링 바깥 1.5 mm. `--no-cut-guides`로 끌 수 있다.

## 배포용은 인쇄보다 비닐 스티커

인쇄는 프로토타이핑용이다. 잉크젯 출력은 색이 바래고 채도가 낮으며 로트마다 다르다.

실제 운용에는 **유색 비닐 원형 스티커**(컬러 코딩 라벨)가 낫다. 색이 훨씬 일정하고 내구성도
좋다. 그 경우 이 시트는 색 후보를 고르고 크기를 정하는 용도로 쓰고, 확정된 지름으로 스티커를
주문하면 된다.

## 지름을 정하는 법

```
d_px = fx · D_m / Z_m           fx = f_mm / 0.00345   (VZ-5MU 픽셀 3.45 µm)
```

VZ 카메라 + 12 mm 렌즈, 작업거리 3 m 기준이다.

```
fx = 12 / 0.00345 = 3478 px

D = 17 mm  ->  19.7 px
D = 18 mm  ->  20.9 px      <- 기본값
D = 20 mm  ->  23.2 px
```

**Bayer 컬러 센서는 R과 B를 전체 픽셀의 25%에서만 샘플링하므로 색 해상도가 휘도의 절반이다.**
지름 하한을 15 ~ 20 px 아래로 내리지 않는 것이 좋다. 렌즈 초점거리나 설치 거리가 다르면 위
식으로 다시 계산한다.
